# Планировщик задач (Task Planner)

Учебный проект по практике. Веб-приложение для управления списком задач

## 🔗 Ссылка на работающий сайт
**https://PPZDL.github.io/task-planner/**

## 📋 Возможности
- Регистрация и вход (данные хранятся локально в браузере)
- Создание, редактирование и удаление задач
- Указание срока выполнения и статуса («Новая», «В работе», «Выполнена»)
- Поиск задач по названию
- Фильтрация по статусу и сортировка по дате
- Сохранение задач для каждого пользователя отдельно 
- Адаптивный дизайн для компьютеров и телефонов
- Собственный фон
- Плашка поддержки

## 🛠 Технологии
- HTML5 (разметка)
- CSS3 (стили, адаптивность)
- JavaScript (логика, работа с DOM)
- localStorage (хранение данных в браузере)

## Структура проекта
- `index.html` — главная страница
- `style.css` — оформление
- `script.js` — логика работы с задачами
- `auth.js` — логика регистрации и входа
- `images/` — папка с фоновой картинкой

## Как запустить локально
1. Скачайте проект (кнопка Code -> Download ZIP).
2. Распакуйте архив.
3. Откройте файл `index.html` двойным кликом в любом браузере.
